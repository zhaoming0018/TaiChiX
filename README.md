# TaiChiX

太极跟练 Web 原型，支持：

- 选择不同太极版本（24 式入门、42 式进阶）
- 启用摄像头做实时姿态识别（MediaPipe Pose）
- 内置真人太极示范视频，可边看边跟练（支持上传本地视频替换）
- 训练中提供“实时跟练展示”（匹配度进度条 + 指标逐项对比）
- 无摄像头时可切换“演示模式”做完整流程验证（自动加速）
- 按动作阶段进行标准度评估与实时提示
- 整套结束后输出总分、评级与改进建议
- 可选语音引导

## 本地运行

1. 在项目根目录启动静态服务：
   - `python3 -m http.server 4173`
2. 浏览器访问：
   - `http://127.0.0.1:4173`
3. 点击“开启摄像头”或“开启演示模式”，选择版本后开始整套训练。

## 技术说明

- 前端：原生 HTML/CSS/JavaScript
- 姿态识别：MediaPipe Pose（CDN 引入）
- 动作评分：依据关节点角度、躯干倾角、肩线水平和步幅等指标，按动作规则加权评分
